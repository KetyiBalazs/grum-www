Color Guidelines

Treat the token table as the only color source. Do not pick a hex by eye, remix a swatch, or add a new color. Page canvas is --background, raised surfaces are --white, and --dark is a quiet fill — never body text. Type uses --text-primary for titles and body, --text-secondary for supporting copy, --text-tertiary for meta and timestamps, and --text-light only on saturated fills. Fade tokens are hairlines, dividers, and overlays, not type.

Map intent, not appearance. --semantic-button / --primary-base fill primary actions; --primary-light is the tint behind them. Error stays in its family: base for icon and message, light for the chip, faded for a wash. Green means synced or success; variant is a non-status accent. If a control has no matching token, reuse the closest semantic role or leave it locked — never approximate. This page is the harness: UI and agents should consume these names so the product cannot drift.
