Manifesto

The design system has to live where the product is actually built.

Request early access

Every product eventually drifts from itself.

Design systems were supposed to stop that. Tokens, styles, components — a shared vocabulary instead of a folder of copies. They helped. Products got more consistent. Teams got faster. Then agents started shipping faster than any one file could keep up with.

A library that only lives in Figma is documenting half the product. The other half is already in code, written by humans or agents, quietly forking the moment someone merges.

Figma once held the system. Now the code does too.

A library once lived in one tool. Now it lives in five.

Shipping once needed a design review. Now an agent can merge before anyone looks.

Building with agents once needed a style guide nobody opened. Now you need a system they can follow.

The new tools didn’t erase designers or engineers. They opened a second path alongside them. We’ll still have teams shipping the traditional way — but agents reshape what gets into production, and how fast it drifts.

Gruum is the layer underneath: the source of truth your humans and your agents both read. It visualizes what’s actually in the code, flags the moment it diverges, and gives everyone one system to use. Not a plugin bolted onto Figma. Not documentation an agent never opens.

Something that will not change: the product still has to feel like one thing. Build on Gruum if you’re ready to keep it that way.
